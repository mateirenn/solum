## Highest-value next steps

1. Add a native incremental repository that persists dirty 256 × 256 tiles and recovery metadata without rewriting the full JSON container.
2. Rust-backed large-map brush, rules, import/export, and analysis workers.
3. Add reusable stamps, richer spline snapping/handles, and full material bed/bank authoring.
4. Full-resolution profiling, configurable history budget, and high-DPI QA.
5. Packaged Windows + Roblox Studio validation.
