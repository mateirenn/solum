# Testing

`pnpm test` runs deterministic terrain-domain tests. The suite covers Roblox scale conversion, normalized/world height conversion, brush falloff, smooth/flatten/slope-enforcement behavior, terrace/ridge/valley/plateau behavior, deterministic noise, slope calculation, layer compositing, material-layer compositing and undo, protection-mask editing and constraints, rectangular and polygon selection constraints, graded road and carved river corridors, deterministic biome painting, material-rule preview and async compact history, terrain statistics, procedural layers with selection/mask constraints, changed-sample undo data, pure heightmap/colormap/manifest export mapping, and tiled `.rterrain` persistence including v1 compatibility, partial edge tiles, corridor metadata, explicit colormap mappings, and asynchronous serialization progress. The current suite has 36 passing tests.

Manual acceptance should cover: create a 16,384-stud project, sculpt a hill, add and hide a mountain layer, paint grass and rock, inspect slope, apply a rule preview, save and reopen the `.rterrain` file, export all three outputs, and compare the 3D preview with the 2D map. Test at 100%, 125%, and 150% Windows scaling when possible.

The browser smoke pass has covered project creation, advanced tools including the slope brush, worker-backed rules preview with visible progress/cancel UI, biome painting, procedural layer generation, export review, a 4,096 × 4,096 sample project, and a clean browser console. The corridor progress/cancel path is covered by source wiring and domain tests but still needs a dedicated browser acceptance pass. The automated suite still does not prove native file dialogs, running an installed desktop binary, Windows DPI behavior, or Roblox Studio import acceptance; those remain explicit manual gates.
