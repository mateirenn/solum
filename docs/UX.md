# UX notes

Solum uses a dense, calm desktop-tool layout: a narrow tools rail, the terrain canvas as the visual center, an inspector/layers rail, and an always-visible sampled 3D preview. Controls speak in Roblox terms—studs, elevation, slope, sea level, and materials—while pixel dimensions are shown as a consequence of the chosen world size.

Keyboard shortcuts:

| Shortcut | Action |
| --- | --- |
| Ctrl+N / Ctrl+O | New / open project |
| Ctrl+S / Ctrl+Shift+S | Save / save as download |
| Ctrl+Z / Ctrl+Y | Undo / redo |
| B / F / S | Brush / flatten / smooth |
| [ / ] | Decrease / increase brush radius |
| Space + drag | Pan canvas |
| Esc | Return to brush |

Shortcuts are ignored while typing. Space-drag and middle-mouse pan are intentionally familiar. There is no tutorial modal; the canvas hint teaches the three essential gestures in place.
