# Security policy

## Supported versions

The latest public beta is the only actively supported release line during the v0.8 beta period.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Use GitHub’s **Report a vulnerability** flow for this repository when available, or contact the repository owner privately through GitHub to request a secure reporting channel.

Include the affected version, reproduction steps, impact, and any minimal proof needed to reproduce the issue. Please allow reasonable time for triage before public disclosure.
