# Future Roblox Studio plugin

This directory is reserved for a future Luau companion. It is intentionally not a dependency of the Solum desktop editor. The first integration contract is the exported heightmap + colormap + manifest consumed by Roblox Studio Terrain Editor.

Any future live bridge must be localhost-only, explicitly paired, token-authenticated, origin-validated, and narrowly scoped. Solum V1 does not open a local control server.
